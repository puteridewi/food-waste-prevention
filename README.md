# Machine Learning-based Food Waste Prevention System Through Predictive Spoilage Risk Assessment and Inventory Prioritization

A  machine learning-driven mobile application designed to help households track perishable groceries, predict spoilage risks, and reduce food waste.

## Problem statement
Households and individual consumers are significantly impacted by the lack of proactive tools for tracking perishable groceries and predicting spoilage risks. Because conventional kitchen management relies heavily on guesswork and static expiry dates rather than dynamic freshness tracking, food is frequently forgotten and allowed to spoil. This ongoing issue contributes heavily to domestic food waste. Implementing a machine learning-based food waste prevention system will enable accurate spoilage forecasting and intelligent inventory prioritization, helping households consume food before it goes to waste.
